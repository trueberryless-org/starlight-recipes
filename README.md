# `starlight-recipes` 🍕

Starlight plugin to create a recipe website.

## Documentation

Read the [Starlight Recipes docs](https://starlight-recipes.netlify.app).

## Package

If you are looking for the Starlight plugin package, you can find it in the [`packages/starlight-recipes/`](https://github.com/trueberryless-org/starlight-recipes/tree/main/packages/starlight-recipes) directory.

## Project structure

This project uses pnpm workspaces to develop a single Starlight plugin from the `packages/starlight-recipes/` directory. A Starlight documentation site is also available in the `docs/` directory that is also used for testing and demonstrating the Starlight plugin.
